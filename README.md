# 市場溫習 | BAFS 市場學互動教學網站

為 DSE 考生而設的市場學互動教學網站，包含 7 個章節、60+ 課題、即時測驗同進度追蹤。

## 功能

- 📚 7 個章節目錄，快速導航
- 🃏 卡片式記憶，點擊翻轉睇例子
- 🏷️ 按 Question Word 篩選課題
- 🔍 關鍵字搜尋
- ❓ 隨機測驗，即時回饋
- 📊 進度追蹤（自動儲存）

## 使用說明

1. 打開首頁揀選章節
2. 每章有 4 個分頁：重點記憶卡、答題框架、例子庫、快速測驗
3. 卡片點擊可翻轉睇例子
4. 測驗答對會自動記錄進度

## GitHub Pages 部署

本網站已設定 GitHub Actions 自動部署，每次推送到 main 分支會自動更新。
